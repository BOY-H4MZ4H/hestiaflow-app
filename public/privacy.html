Kebijakan Privasi

Terakhir diperbarui: 17 Oktober 2026.

1. Data yang kami kumpulkan

Saat kamu masuk dengan Google, kami menyimpan nama, alamat email, dan foto profil dari akun Google-mu — hanya untuk login dan menampilkan akunmu. Saat kamu memakai layanan, kami menyimpan API key HestiaFlow milikmu, riwayat Panen Akun, dan pemakaian model (nama model + jumlah token).

2. Data yang TIDAK PERNAH kami tampilkan

Kredensial dapur (Base URL asli provider, API key asli provider, email sementara, dan sandi hasil Panen Akun) tidak pernah ditampilkan ke pengguna mana pun, tidak pernah muncul di response API, log, atau halaman web. Kamu hanya melihat Base URL HestiaFlow, API key HestiaFlow, dan Credit-mu sendiri.

3. Cara kami memakai data

Data dipakai untuk menyediakan gateway (meneruskan permintaanmu ke provider), mengelola kunci dan credit, serta menjaga keamanan akun. Kami tidak menjual data-mu dan tidak membagikannya ke pihak ketiga, kecuali untuk meneruskan permintaan API-mu ke provider (tanpa identitas pribadimu).

4. Cookie & sesi

Kami memakai cookie sesi agar kamu tetap masuk. Cookie ini tidak dipakai untuk pelacakan iklan.

5. Penghapusan data

Kamu bisa menghapus hasil Panen Akun-mu sendiri dari Halaman Pengguna (tombol Hapus) — kunci HestiaFlow dan data akun hasil panen itu ikut terhapus. Untuk menghapus akun sepenuhnya, hubungi operator melalui Panel Admin.

6. Hubungi kami

Pertanyaan soal privasi bisa disampaikan melalui Panel Admin HestiaFlow.
